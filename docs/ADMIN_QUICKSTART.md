# 发布活动：管理人员速查版

这一页只讲你每次发活动要做的事。完整说明在 [HOW_TO_PUBLISH_EVENTS.md](HOW_TO_PUBLISH_EVENTS.md)。

## 你需要的东西

- Studio 地址（技术负责人会发给你，形如 `https://necina.sanity.studio`）
- 一个已被邀请的邮箱（收到过 Sanity 的邀请邮件）

## 发布一个新活动

1. 打开 Studio 地址，登录。
2. 左侧点 **Event**，再点右上角 **+** 新建。
3. 填下面这几项：

   | 填什么 | 例子 |
   |---|---|
   | Stable ID | `ai-summit-2026`（小写、数字、连字符；发布后别改） |
   | URL slug | 和 Stable ID 一样 |
   | Title (EN) / Title (中文) | 活动标题 |
   | Date (EN) / Date (中文) | `March 14, 2026, 6–9 PM` / `2026年3月14日 18:00–21:00` |
   | Venue (EN) / Venue (中文) | 地点 |
   | Category | 下拉选一个 |
   | Status | 没办的选 `upcoming`，办完的选 `past` |
   | Description (EN) / (中文) | 简介 |
   | Sort order | 想排最前面填 `-1`（数字越小越靠前） |
   | Registration URL | 报名链接（没有就空着） |

4. **Cover image** 点 Upload 上传一张图。这是列表和详情页都会用的图，一定要传。
5. 右下角点 **Publish**。

一分钟内，网站上就能看到。

## 修改已有活动

在 **Event** 列表里点开它，改完 **再点一次 Publish**。不点 Publish 的改动只是草稿，网站看不到。

## 活动办完了

打开它，把 **Status** 改成 `past`，点 **Publish**。

## 不想让它出现在网站上

打开它，点标题旁边的 **⋯**，选 **Unpublish**。

## 三条规矩

1. 中英文字段成对填，不然切换语言时会缺内容。
2. Stable ID 发布后不要改。
3. 网站是公开的，别在活动里放内部信息。

## 出问题了

- **网站上找不到**：确认点了 Publish；确认 Status 对（`upcoming` 在 Upcoming 标签，`past` 在 Past 标签）；等一分钟刷新。
- **图片不显示**：Cover image 没传。
- **登录不了**：找技术负责人确认你的邮箱已被邀请。
- 其他问题：看 [完整教程的常见问题](HOW_TO_PUBLISH_EVENTS.md#常见问题)。
